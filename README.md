E-Pood
Node.js ja Express'iga ehitatud e-poe õppeprojekt, mis kasutab JSON-põhist andmekihti ja serveripoolt renderdatud vaateid.

Kaustastruktuur
Kaust / fail	Kirjeldus
server.js	Rakenduse käivituspunkt (Express server)
views/	Serveripoolt renderdatavad vaated
constructors/	JavaScript klassid / konstruktorid
data/	Rakenduse andmefailid
project/	Projekti põhiloogika
data.json	Andmete salvestuskoht
package.json	Sõltuvused ja npm-skriptid
